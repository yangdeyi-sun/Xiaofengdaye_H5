# 0.5.1 数值与显示修正

- 全部10种花丛的基础储量仅增加3：野花24→27、三叶草30→33、向日葵260→263、薰衣草480→483、稀有生态800→803、油菜300→303、雪莲400→403、睡莲420→423、仙人掌360→363、屋顶月季380→383；恢复等待仍为3秒。
- 采集蜂单次携带量4→12；同路线、同花期的理论运输效率约为原来的3倍。实际每秒收入仍受距离、季节和花源存量影响，不能将每秒效率误称为单次采集量。
- 全部30项建筑属性升级重定价：初级采集/侦察/加工30–60蜂蜜起，中期80–180，高阶特殊幼虫240；每级涨幅28%–40%。蜂蜡需求保留。基础加工速度升级40蜂蜜+5蜂蜡。
- 进化腔8项研究首级450–800蜂蜜，每级涨幅60%；蜂王浆需求保留。建筑建造、孵化和分化价格独立计算。
- 花蜜水滴统一改为暖黄色。花丛保留原位置、宽度与绿色库存条，仅略微加粗、加深底色并增加浅色描边；不新增条下数字或倒计时，不调整页面布局。
