# 音频重新划分（0.3）

旧版同时播放背景音乐、环境声、天气声，再加上产卵、孵化、运蜜、酿蜜、战斗等几十种自动音效，听起来很乱。0.3 版删除了全部旧音频，按下面的规则重新划分。

## 原则

- **同一时刻只有一首背景音乐**，不叠加环境声和天气声。
- **只给玩家亲手做的事和需要注意的事配音效**。蜜蜂在后台自动做的事（产卵、孵化、运蜜、酿蜜、筑蜡、摇摆舞、发现花田、战斗细节）不出声。
- 同时最多 4 个音效；两个事件提示之间至少间隔 1.2 秒；事件提示响起时，背景音乐自动压低。
- 缺少的文件会被自动跳过（静音），不会报错。可以先放一部分，游戏照常运行。

## 需要制作的文件（共 15 个）

把文件放到 `public/audio/v2/` 对应目录，文件名必须一致。可以直接放 `.mp3`；也可以放 `.wav`，然后运行 `npm run audio` 转码（需要 ffmpeg）。放好后重新运行 `npm run build` 或 `npm run dev`。

### 1. 背景音乐 `bgm/`（循环播放）

| 文件 | 什么时候播 | 建议 |
|---|---|---|
| `bgm_home.mp3` | 首页 | 轻快、温暖，60–90 秒可循环 |
| `bgm_game.mp3` | 游戏中（春、夏、秋） | 安静、不抢注意力，适合长时间挂机，90–120 秒可循环，首尾能无缝衔接 |
| `bgm_winter.mp3` | 冬季 | 与 `bgm_game` 同一主题的慢速、偏冷版本 |

### 2. 界面 `ui/`（0.1–0.4 秒）

| 文件 | 触发 |
|---|---|
| `ui_tap.mp3` | 点按钮、切换标签、打开面板、开关 |
| `ui_confirm.mp3` | 操作成功（建造、产卵、保存等） |
| `ui_error.mp3` | 资源不足、操作失败 |
| `ui_reward.mp3` | 领取奖励、看完广告领奖 |

### 3. 玩家动作 `action/`（0.2–0.8 秒）

| 文件 | 触发 |
|---|---|
| `act_collect.mp3` | 手动点花采蜜。最高频的声音，要非常轻、短，听很多次也不烦 |
| `act_build.mp3` | 放置巢房、扩建格子 |
| `act_upgrade.mp3` | 升级属性、完成研究、点天赋 |

### 4. 事件提示 `event/`（0.8–2 秒）

| 文件 | 触发 |
|---|---|
| `evt_season.mp3` | 换季、熬过冬天 |
| `evt_threat.mp3` | 胡蜂、蜘蛛网、蜡螟、熊来袭 |
| `evt_victory.mp3` | 击退敌害 |
| `evt_achieve.mp3` | 任务完成、里程碑、成就解锁 |
| `evt_swarm.mp3` | 分蜂出发 |
| `evt_offline.mp3` | 离线归来弹窗 |

## 代码位置

- `src/infrastructure/AudioCatalog.ts`：音效分类和文件路径。游戏里仍用旧名字触发声音，这里统一映射到新分类；映射为空的就不出声。想让某个行为重新出声，改这里的映射即可。
- `src/platform/BrowserAudioService.ts`：播放规则，包括背景音乐切换、音效并发上限和事件压低音乐。
- 设置里的音量调节只剩“音乐音量”和“音效音量”两项。
