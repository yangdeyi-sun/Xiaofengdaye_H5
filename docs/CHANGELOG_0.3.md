# 0.3.0 修改说明

> 以下为历史版本记录。当前版本已改为主动繁育、瓶颈驱动的发展流程，并只维护抖音小游戏与 TapTap Android，不再执行鸿蒙一致性检查。当前说明见 [发布说明](RELEASE.md) 与 [发展流程](PROGRESSION_FLOW.md)。

## 1. 新手节奏：储蜜格之前太慢

**原因**
- 建造要花蜂蜜，点花只得到花蜜。开局蜂巢每秒只能把 1.2 花蜜酿成 0.6 蜂蜜，点得再快也没用，花蜜仓很快就满了。
- 第一只采集蜂出生后，自动产卵、自动培养会把蜂蜜一直花光，所以储蜜格的钱迟迟攒不够。

**修改**
- 开局基础酿蜜速度 1.2 → 3.0 花蜜/秒（即每秒 1.5 蜂蜜）。每秒点 1～2 下就不会浪费。
- 采集蜂巢房 230 → 140 蜂蜜，储蜜格 220 → 160 蜂蜜。
- 蜂巢开始自行运转后、第一个储蜜格建成前，自动繁育会先给储蜜格留出蜂蜜，不再把蜂蜜花光。
- 新手引导延伸到储蜜格，节点见下表。
- 提示行会显示“蜂蜜 进度/所需（每秒酿多少）”。花蜜满了时会提示“花蜜满了，不用再点 · 约 X 秒后可建”。

**新手引导节点**（`src/domain/GameConfig.ts` 里的 `TUTORIAL`）

| # | 节点 | 完成条件 |
|---|---|---|
| 1 | 采集花蜜 | 点花丛采到第一份花蜜 |
| 2 | 蜂后产卵 | 产下第一只幼虫 |
| 3 | 建造侦察蜂巢房 | 建成侦察蜂巢房 |
| 4 | 培养侦察蜂 | 第一只侦察蜂出生 |
| 5 | 建造采集蜂巢房 | 侦察蜂跳完摇摆舞后建成 |
| 6 | 培养采集蜂 | 第一只采集蜂出生，此后自动产卵、自动培养 |
| 7 | 建造储蜜格 | 建成储蜜格，正式四季开始，新手阶段结束 |

**仿真结果**（`npm run sim`，游戏时间）

| 里程碑 | 改前 | 改后（积极点击） | 改后（每秒约 1 下） | 改后（每 2 秒约 1 下） |
|---|---|---|---|---|
| 第一只采集蜂 | 7:32 | 2:48 | 3:11 | 5:41 |
| 储蜜格 | 19:25 | 4:01 | 5:13 | 7:34 |
| 首次分蜂 | 125:44 | 106:39 | — | — |

用 `SIM_TAPS=0.5 npm run sim` 可以模拟点得少的玩家。

## 2. 换季弹窗图片不显示

是路径写错了：横幅用的图标 `xf_status_info.svg` 不存在。另外离线弹窗的 `illustration_offline_return`、熊来袭弹窗的 `illustration_bear_warning`、隐私和协议的两个图标也都指向不存在的文件。

现在全部改为已有的图片。季节横幅显示当前季节的图标，“事件动画”样式的换季卡片也补上了样式。

## 3、4. 蜂巢里蜂后和建筑图标“消失”；建造需要时间吗

**原因**：建好一个巢房后会同时触发两个特效，盖住了周围：
- 建造特效有 1.7 个格子大，会盖住相邻巢房；
- 建造通常会同时完成一个任务，“任务完成”特效画在屏幕正中，是一个很大的蜂巢图案，刚好盖住中央的蜂后和周围的建筑，持续约 1 秒。

**修改**：建造特效缩小到只占自己这一格；任务、成就等全屏特效移到屏幕上方并缩小，不再盖住蜂巢。

**建造需要时间吗？** 不需要。放下去的瞬间就建好了，资源也是那一刻扣除。之前看起来“没立即出现”，是被上面两个特效挡住了。

另外：蜂巢没有空格时点“放置”，以前会让你点一个根本不存在的发光空格。现在会直接提示先扩建。

## 5. 侧边栏往下翻会跳回顶部

**原因**：面板每秒重绘一次来更新数字，重绘时整块内容被替换，滚动位置就丢了。

**修改**：重绘前记下每个滚动区域的位置，重绘后还原；正在滑动时暂停定时重绘。弹窗里的长文本（例如隐私政策）同样适用。

## 6. 背景音乐太杂

删除全部旧音频，重新划分为 3 首背景音乐 + 12 个音效。规则和需要制作的文件清单见 [AUDIO_PLAN.md](AUDIO_PLAN.md)。新文件放进 `public/audio/v2/` 之前，游戏是静音的，不会报错。

## 7. 广告先占位

还没有接入任何广告 SDK 时，点广告按钮会直接发放奖励，并提示“广告位占位，已直接发放”。接入 SDK 后会自动换成真实广告。在抖音、TapTap 小游戏里，`adUnits.ts` 里还没填广告位 ID 的点位也按占位处理。

H5 里想看广告弹层流程，可以在网址后加 `?ads=mock`；加 `?ads=none` 模拟“暂无广告”。

## 其他

- 开发服务器（`npm run dev`）以前对不存在的文件返回首页内容和 200 状态码，导致缺失的图片被每帧重复请求。现在返回 404，并补上了 mp3 的类型。
- 网址加 `?debug=1` 时，可在浏览器控制台用 `window.__xf`（会话）和 `window.__xfui`（界面）调试。
- 有意与鸿蒙原版不同的核心文件：`GameConfig`、`ColonyService`、`Guide`、`SceneRenderer`。`npm run verify:core` 会跳过这 4 个文件，其余仍要求逐字节一致。
