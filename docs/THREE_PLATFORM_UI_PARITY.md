# 三端界面一致性验收约定

2026年10月19日用户要求：抖音版与安卓版、网页版一模一样。

## 基准与完成标准

- 基准为原安卓版/网页版的完整界面与行为，现已抽离为 `GameUI.ts` + `styles.css`。
- 三端使用同一套完整界面定义、导航状态、事件调度和命令处理；平台层只适配绘制、输入、安全区、音频、广告与存储。
- 不允许独立维护一份删减功能的抖音界面，不允许把网页/安卓版降级成当前简化Canvas界面。
- 同一存档、设置、视口和模拟时刻下，界面的美术、配色、文字、控件、排布与可操作结果均一致。不同屏幕尺寸使用同一套自适应规则。
- 浏览器中的Canvas预览通过后，还须用抖音开发工具及真机验收；单纯构建成功不等于完成一致性。

## 实现边界

抖音小游戏运行时没有浏览器DOM/BOM，使用上屏Canvas，因此不能直接把HTML页面作为小游戏入口运行。应抽离完整版的界面与控制逻辑，再实现宿主适配；不能仅改入口导入名或伪装成网页即声称完成。[抖音小游戏官方开发指南](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/dev-guide/bytedance-mini-game)

验收截图至少覆盖320×568、390×844、平板与桌面尺寸；同尺寸三端对照。对每种操作验证资源变化、存档、导航和广告发奖结果一致。现有免费移动、音频与离线时长改动必须保留。

## 当前状态

已完成代码层面的完整界面统一，旧 `src/app/minigame/CanvasUI.ts` 已删除：

| 模块 | 职责 |
|---|---|
| `src/app/GameUI.ts` | 三端唯一的完整页面、导航状态、教学、弹窗、提示调度与命令处理 |
| `src/app/BrowserUI.ts` | 兼容导出，不再含独立页面实现；网页及安卓继续使用原DOM宿主 |
| `styles.css` | 三端共用样式与响应式断点；显式行高和统一滑块外观消除浏览器默认控件差异 |
| `src/app/ui/FullCanvasUI.ts` | 抖音输入、滚动、多点触控、场景与界面合成 |
| `src/app/ui/VirtualDocument.ts` | 完整控制器所需的节点、选择器、事件与滚动接口；不伪造浏览器全局变量 |
| `src/app/ui/StyleSheet.ts` / `CanvasDocumentRenderer.ts` | 解析共用样式，以Yoga布局并绘制完整界面；缓存文字度量和样式以控制更新耗时 |

美术继续来自同一份资源。抖音所需PNG由原WebP无损转换，保留解码后的RGBA像素，不再将全部素材减色到128色。只剔除共用图集清单中永远不会请求的重复高清页，高清/半尺寸的选择规则仍相同。SVG图标转换为同图案的192像素PNG。没有强制抖音开启省电模式。

## 已执行的验证

- 类型检查；115项模拟内核检查、58项浏览器适配检查、57项完整界面宿主检查。
- 使用真实抖音入口构建JS，在没有 `window`、`document`、`location`、`navigator` 和DOM元素类的VM中，经过冷启动、隐私确认、首页、完整设置页、触摸及前后台切换。
- 对照15个完整面板的按钮动作、参数与禁用状态，全部相同；对比390×844下的页面截图。
- 检查320×568、390×844、844×390、1024×768、1440×900的侧栏和滚动视口；检查加速、协议等完整弹层。检查滚动位置保持、滑块、拖动、双指缩放和免费移动巢房。
- H5、抖音构建及安卓版APK构建通过；APK校验确认包含相同的网页JavaScript/CSS，没有混入小游戏预览入口。抖音包约13.91 MB，仍受现有20 MB构建上限检查约束。
- 159个打包PNG逐一与原WebP解码后的RGBA比对，像素一致；所有SVG图标与16个MP3均已打包。

## 发布验收边界

项目尚未配置抖音AppID，因此没有进行抖音开发工具联网/真机验收。代码与本地宿主验收已完成，**不把模拟宿主通过写成抖音真机通过，也不声称所有设备逐像素零差异**。原生宿主的字体、画布滤镜与系统控件仍需真机对照；不支持画布滤镜的宿主采用缩小再放大的背景柔化回退。

宿主屏幕方向能力也应与界面响应式区分：抖音配置只提供固定竖屏/横屏，当前保持原有竖屏入口；其余尺寸的共用界面已用本地宿主验证。[抖音小游戏配置](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/framework/mini-game-configuration)
