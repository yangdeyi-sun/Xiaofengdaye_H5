# 0.5 修改说明（按反馈逐条对应）

| # | 反馈 | 修改 |
|---|---|---|
| 1 | 图标丑，换回之前的 | 安卓启动图标改回游戏原有的皇冠蜜蜂图标（`app_icon`），提供各密度 PNG 与 Android 8+ 自适应图标；网页也用它做标签页图标。不再使用临时画的矢量图标。 |
| 2 | 点蜂巢里的建筑，图标消失、进不了详情 | 根因 1：触屏点开面板后浏览器补发的 click 落在刚出现的遮罩上，把面板立即关掉。画布 `touchend` 阻止补发 click，并在点按后 0.45 秒内忽略遮罩点击。根因 2：选中格子用不透明的“选中”贴图盖住了建筑，改为只描金色外框。 |
| 3 | 侧栏部分图片没加载 | 侦察蜂巢房的“花源储量”“花源恢复效率”两项升级引用的图标文件不存在，补画 `xf_stat_scout_stock.svg`、`xf_stat_scout_regrowth.svg`。已逐个打开全部面板检查，没有其他缺图。 |
| 4 | 采蜜改成按住持续采 | 先完成两次手动点击，随后按住花丛持续采蜜（按下立刻采一次，约 0.25 秒后每秒 3 次）；花丛采空时停在原地等待重新开花。新手提示与“花丛”介绍改为“按住花丛不放”。 |
| 5 | 侧栏“✕”左边的按钮不要跳到暂停界面 | 改为“返回上一级”：从面板里点进去的下一级（如蜂巢总览 → 巢房升级）逐级退回，最上层回到蜂巢总览，总览处隐藏该按钮。“保存并返回首页”移到「设置」底部；安卓返回键同样逐级退回。 |
| 6 | 侧栏收缩图标改成蜂窝 | 新增七格蜂窝图标 `xf_nav_comb.svg` 用于侧栏把手。 |
| 7 | 新手结束弹窗文案 | 交接弹窗改为专门的“蜂后的托付”样式，去掉“这是什么/有什么用”，按钮“交给我吧”；删除与之重复的“接下来这个王国交由你”横幅。 |
| 8 | 花田界面点蜂巢进入蜂巢 | 点花田中央的蜂箱直接切到蜂巢内部（抖音版同步）。 |
| 9 | 花丛恢复太慢 | 采空后的恢复等待 18 秒 → 3 秒（`economy.flowerRecoverSec`，侦察房升级仍会缩短）。 |
| 10 | 酿蜜起步太快、酿蜜房没存在感；花丛花蜜增加 3 | 蜂巢基础酿蜜 0.6 → 0.4 花蜜/秒，每只成年蜂附加 0.12 → 0.04；酿蜜房逐级提速：第 k 座提供 1.8 × (1 + 0.5 × (k−1)) 花蜜/秒，巢内工蜂每只 2.0。第一座酿蜜房即是基础酿蜜的约 4.5 倍。野花丛储量 24 → 27、三叶草地 30 → 33。仿真：建成酿蜜房 0:49 → 1:12，首次分蜂节奏与原来相近。 |
| 11 | 扩建点了没反应 | 同第 2 条的触屏误关面板。另外：点外圈“+”格子蜂蜡够就直接扩建；侧栏「建造」和蜂巢总览新增“扩建一格”，并显示下一格价格和现有蜂蜡。（扩建仍需先建成第一个储蜜格。） |
| 12 | 秋季地图丑、冬季地面要全白 | 秋季不再飘落叶、不铺落叶贴图，整片地面转为暖金色草甸；冬季地面整片积雪覆盖，保留下雪。 |
| 13 | 退出后继续经营、离线收益、广告翻倍 | 离线结算不再限制“培养采集蜂前只算 5 分钟”，按离线收益上限完整结算；短暂切后台也照常结算。回到首页再进入游戏、或关掉应用后重新打开，离开 30 秒以上都会弹出“欢迎回来”收益报告，可看广告翻倍。 |
| 14 | 资源下方直观显示采蜜/酿蜜进度和蜂种数据 | 资源栏下新增产线条：采蜜速度 → 酿蜜负荷进度条（显示满负荷/酿不完/缺花蜜）→ 蜂蜜速度；下方滚动显示各蜂种数量、巢房等级和运行效率，点一下打开蜂群面板。 |
| 15 | 双击缩放地图 | 花田空地双击放大到点击处，再双击平滑回到默认视野（鼠标双击同样有效）。 |
| 16 | 手机/平板/电脑适配，引导提示显示不全 | 顶部信息改为纵向排列的信息栏，资源、产线条、提示行不再互相遮挡；提示行完整换行显示；修复资源图标与数字错位；平板/电脑侧栏宽度分档；蜂巢视图让出顶部信息栏的高度；窄屏产线分行显示，横屏仍保留蜂种明细。 |
